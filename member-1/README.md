## Quy ước dùng trong bộ tài liệu

- **[Đã xác nhận]**: nội dung đã được nhóm trưởng phê duyệt. *Ở phiên bản v0.1 chưa có mục nào ở trạng thái này.*
- **[Đề xuất]**: nội dung thành viên 1 đề xuất dựa trên bản phân công; cần nhóm trưởng duyệt.
- **[Chờ quyết định]**: câu hỏi mở, tham chiếu mã `Q-xx` trong [business-rules.md](business-rules.md).
- Mã yêu cầu `FR-xx`, `NFR-xx`, quy tắc `BR-xx`, câu hỏi `Q-xx`, Use Case `UCxxx` (mã UC là đề xuất, cần thống nhất với thành viên 2).
- Sơ đồ viết bằng Mermaid (xem được trực tiếp trên VS Code / GitHub / GitLab). Khi đưa vào báo cáo Word, xuất ra PNG/SVG độ phân giải cao.
